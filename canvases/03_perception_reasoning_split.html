§1 The question this answers

The prior draft (§3.3) showed that making the evidence-first prompt a machine-readable table raised every aggregate F1 — but for Gemini that rise was an F1 illusion: it flagged 76% of studies abnormal when only 56% are, so precision collapsed and accuracy did not move. The prompt changed the operating point, not the diagnosis.

That left an open question, put sharply in review:

Does the structured prompt actually improve visual perception, or does it simply encourage the model to report more findings? — reviewer follow-up, "Suggestion #1b"

A single-pass prompt cannot answer this, because perception and reasoning happen in the same forward pass — a wrong answer can't be charged to bad seeing versus bad reasoning. So we separated them.

Going from unstructured to structured, F1 climbs (0.585 → 0.724) and recall nearly doubles (0.44 → 0.83). But findings/study goes 1.0 → 2.3, %-flagged 27% → 76%, precision falls 0.89 → 0.63, and accuracy does not improve (0.654 → 0.635). Forbidding the diagnosis entirely (perception-only) reproduces the same picture. The extra F1 is extra reporting.

Given the findings, the text-only reasoning step is faithful: it reproduces the Stage-A abnormal/normal call 83% of the time, its over-calling collapses to a well-calibrated 55%-flagged rate (true 56%), and accuracy even nudges up to 0.674. Crucially:

perception-bound

77% of triage errors

Of Stage B's 246 wrong calls, 77% were already wrong in Stage A — the model never saw the finding, so no amount of reasoning could recover it.

reasoning is not the bottleneck

a coin-flip override

On the 126 cases where reasoning overrides perception's call, it is right just 56% of the time — it neither rescues nor wrecks the diagnosis. The bottleneck is vision.

§4 A measurement-discipline catch

The first scoring pass read Stage B by mining its free-text explanation, and reported 98%-flagged / 0.572 accuracy — a reasoning collapse that never happened. The cause: the Stage-B explanation dutifully restates every finding it was handed ("no cardiomegaly, no edema, no consolidation…"), and a naïve extractor scrapes those negated names as positives. Scoring the model's committed primary diagnosis instead gives the honest 55%-flagged / 0.674 above. Same lesson as the rest of the paper: the operationalization can manufacture the artifact, and only decomposition reveals it.

§5 The same experiment on the local medical model

MedGemma-4B run in progress

The two-stage pipeline is running on MedGemma-4B (8-bit, local via MLX) so the perception-vs-reasoning attribution can be reported per model — matching the paper's finding that the same prompt edit had opposite outcomes on Gemini and MedGemma. Because §3.3 showed structuring was a genuine gain for MedGemma (precision and recall rose together), the prediction here is the mirror image of Gemini: more of MedGemma's improvement should trace to perception. §6 What this adds to the paper

The prior draft could say "structured prompting changes the operating point." This turns that into a mechanism and a location:

— Mechanism. For Gemini the structured prompt raises F1 by increasing how much the model commits, not how well it perceives; accuracy is invariant to the reformatting.

— Location. Isolating the two stages shows the ceiling is a perception ceiling: ~⅘ of triage error originates in what the model failed to see, and an error-free reasoning step cannot buy it back. This is a concrete, testable claim reviewers asked for, and it strengthens the paper's central thesis — a rising F1 must be decomposed before it is called an improvement — by showing exactly which faculty the improvement did, and did not, touch.

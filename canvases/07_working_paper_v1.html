Prompt Format and Model Choice in Radiology VLMs — Working Paper

Working paper · Radiology AI · Draft

Prompt format and model choice shape radiology VLM reasoning — and why a rising F1 can still mislead

[Author(s), affiliation]  ·  Evaluation without expert radiologist annotation  ·  IU X-Ray test split, n = 754, two models × five prompts

Abstract

Background. Two design choices for radiology vision–language models are usually made by habit: how the model is prompted, and which model is used. We study both without radiologist annotation, using public reports and automated scoring as the reference.

Methods. A large general model (gemini-2.5-flash) and a small, 8-bit, laptop-run medical model (MedGemma-4B) each read 754 chest radiographs under five prompts (direct, chain-of-thought, differential, evidence-first, uncertainty-first). Every study is read under all prompts by both models (fully paired). Outputs are scored for accuracy, claim-level groundedness, calibration, and blind LLM-judge reasoning quality.

Findings. (1) Prompt format changes faithfulness and calibration: chain-of-thought reads as more coherent while becoming significantly less faithful. (2) The two models occupy opposite operating points rather than one dominating: the local medical model is far more sensitive (over-calls, higher recall and F1) while the general model is more precise and more accurate on the actual normal-vs-abnormal decision (higher on 3 of 5 prompts, significant). (3) The same prompt edit — a structured evidence-first variant — has opposite outcomes by model: for the general model it raises F1 purely by over-calling (precision and accuracy fall, non-significant); for the medical model it raises precision, recall, and accuracy together (p<0.0001), a genuine gain. A rising F1 must be checked against precision and accuracy, and that check is model-specific. Results support comparative claims about prompt and model choice, not clinical readiness.

1Introduction

When a model reads a chest X-ray we usually judge only whether its final label is right. Two other properties matter for trust — whether its explanation is supported by what is visible, and whether its confidence tracks its correctness — and behind both sits a rarely-tested question: does it matter which model, or how we prompt it?

We study both levers — five prompting styles crossed with two very different models — on chest-X-ray interpretation, scored automatically against public radiology reports so no radiologist annotation is required. We pre-registered four hypotheses about prompt format:

  • H1Evidence-first improves groundedness.
  • H2Uncertainty-first reduces overconfidence.
  • H3Chain-of-thought / differential look more convincing without being more faithful.
  • H4Prompt effects are larger on ambiguous cases.

We then add a model-level question — does a smaller medical model, prompted the same way, read radiographs better than a larger general one? — and a cautionary follow-up on whether "improving" the best prompt actually improves the model or merely its F1.

2Methods

Detailed for reproduction; each subsection states both what and why.

2.1Data

IU X-Ray (OpenI): 3,826 public, de-identified studies. A balanced 754-study test set spans six difficulty strata assigned automatically from report hedging, inter-labeler disagreement, and finding counts. It is public, so it can be sent to a commercial API without a data-use agreement.

2.2Design and prompts

Each model receives the image only (plus the one-line indication); the report is held out as an independent reference, so "groundedness" means agreement with a source the model could not have copied. The five prompts share one instruction frame; only the reasoning scaffold changes (direct / chain-of-thought / differential / evidence-first / uncertainty-first).

2.3Models and scoring

gemini-2.5-flash (API, JSON output, hidden reasoning disabled) and MedGemma-4B (8-bit, local via MLX; prompted in free text because the 4B model's perception collapses under strict JSON; confidence taken from its token log-probabilities). Reports are labeled into the 14 CheXpert findings with CheXbert. Accuracy is hierarchy-aware (a parent finding matches its children) and reported across a granularity ladder (13 fine classes, a reliable-11 subset, three clinical groups, binary triage). Comparisons use paired McNemar / Wilcoxon.

3Results — prompt format (large model)

3.1Diagnostic performance

Evidence-oriented prompts lead (Table 1). Absolute finding-level F1 is modest — expected: a 2025 supervised ensemble reaches only ~0.39 F1 on this exact task, and micro-F1 gives no credit for correctly clearing a normal chest (63% of studies). Per-study metrics that do credit normals run ~0.50–0.62.

3.2H3 — reasoning reads better without being more faithful (supported)

The central prompt finding. Chain-of-thought makes the output significantly more coherent-sounding and significantly less faithful (Figure 1, paired Wilcoxon vs direct, n=754).

3.3A follow-up: does structuring evidence-first actually help?

We tried to improve the best prompt (evidence-first) by making its finding stage a machine-readable table — a structured evidence-first variant, run on both models. Every aggregate F1 rose (Table 2) — but the two models earn that rise in opposite ways, and only one of them is a genuine improvement.

The same edit, opposite outcomesStructuring evidence-first is not a universal improvement or a universal artifact — it depends on the model. For Gemini it is an F1 illusion: the model over-calls, and every aggregate metric rewards that except accuracy. For MedGemma it is a real, significant gain on every axis at once. The lesson is the same as H3 at the metric level — a single score can move for the wrong reason, and the reason is model-specific — but the correct response here is not to discard the structured prompt, only to check precision and accuracy before crediting it. A held-out confirmation would still strengthen the MedGemma result before it is reported as established.

Correction — no clean winnerAn earlier reading of this comparison called MedGemma the triage winner "on all five prompts." That was an F1 artifact of over-calling: F1 rewards recall, and MedGemma names 2–3× more findings than Gemini. On the fair accuracy metric neither model dominates — Gemini is more precise and more accurate overall (significantly so on 3/5 prompts), MedGemma more sensitive. The right claim is a precision/recall (specificity/sensitivity) tradeoff, chosen by the clinical goal — screening vs. confirmatory — not "the small medical model wins."

Two further points. Reasoning-format effects are model-dependent — MedGemma's least-conservative prompts (direct/ddx) maximize its recall-driven F1, while Gemini's evidence-first/uncertainty-first maximize precision; prompt tuning does not transfer. And both models are badly calibrated: MedGemma's confidence is no more discriminative than Gemini's (85.0 correct vs 85.1 wrong).

5Reference reliability

How much does the noisy reference cap the fine-grained scores in Table 1? We stratify F1 by how strongly three independent report labelers (rule-based, CheXbert, and VisualCheXbert — a model trained to correct report-vs-image label mismatch) agree on each finding, and score separately on cells they agree on confidently versus cells they do not (Table 6). This does not change Table 1's headline numbers; it explains a share of them.

6Discussion

Two levers set by habit both move the results. Prompt format changes faithfulness and calibration — most sharply, chain-of-thought reads better while being less grounded. Model choice changes the operating point: the local medical model and the large general one trade sensitivity for precision rather than one dominating, so which is "better" depends on the metric and the clinical goal.

The recurring lesson is one of measurement discipline, and the structured-prompt follow-up sharpens it: the identical edit produced an F1 illusion in one model and a real gain in the other, and F1 alone could not tell the two apart — nor could the reference-confidence stratification of §5, which showed the same over-calling signature for MedGemma regardless of whether the underlying prompt effect was genuine. Only decomposing into precision, recall, and accuracy (Table 3) distinguished them. No single number tells the story, and the same check does not generalize across models — each new model or prompt needs its own precision/accuracy audit before a rising F1 is called an improvement.

7Limitations

  • Report-derived reference. Ground truth is what was dictated, not what is visible; two labelers agree at only F1 0.771 — an upper bound.
  • Asymmetric evaluators. The large model outputs JSON (so groundedness and the judge apply); the 4B model runs free-text, so the model comparison rests on accuracy and calibration.
  • Uninformative confidence in both models limits calibration to detecting overconfidence.
  • Two models, one dataset. Generalization is untested. The structured-prompt follow-up needs a held-out confirmation before any claim.
  • Comparative, not clinical. Results support claims about prompt and model choice, not clinical readiness.

8A note on evaluation integrity

During analysis we audited the scoring code and fixed defects in the evaluation, not the models — most consequentially, ignoring the CheXpert label hierarchy (26% of all false positives) and not scoping negation (so "no pneumonia" scored as pneumonia; fixing it lowered some scores and was kept because it is correct). Correcting these roughly doubled the fine-grained numbers. The LLM judge had silently failed at 1.3% coverage; it was traced, fixed, and re-run to 100%. We also record rejected shortcuts to a higher headline — a class-selection search that kept a single finding, and the over-calling structured prompt of §3.3 — neither of which is reported as an improvement. The numbers above are what survived that scrutiny.
